# Idle Miner

An idle mining game for Android: hire workers, run the lift and the wagon, upgrade everything and dig deeper.

## Download

**[⬇ Latest version](https://github.com/RLT-Newside/idle-miner-releases/releases/latest)**: under *Assets*, tap `IdleMiner-x.y.z.apk`.

## Install on your phone

1. Download the `.apk` on your Android phone (Android 7.1 or newer, 64-bit).
2. Open it. If Android asks, allow your browser or file manager to **install unknown apps**.
3. Tap **Install**.

## Updating

Download the newer `.apk` and open it the same way. It installs **over** the old version and **keeps your progress**,
so there's no need to uninstall first. (Uninstalling deletes your save.)

## Checking a download

Each release lists the APK's SHA-256. All releases are signed with the same key; Android refuses an update signed
with a different key, so a tampered APK can't silently replace the game.
